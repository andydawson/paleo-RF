# Notes for agent sessions

Read `CONTRIBUTING.md` for the version-control protocol before making changes.
Summary: work on `chris-dev` (trunk) or topic branches off it; never touch
`legacy` (frozen snapshot of the original code) or `main`; commit each atomic
change with a why-focused message; merges to `main` need explicit approval.

`CODE_MAP.md` gives a high-level description of every script and its data
inputs/outputs.
